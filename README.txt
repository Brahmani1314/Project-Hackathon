ONLINE EXAMINATION SYSTEM - UPDATED PROJECT

Files:
- index.html, signup.html, login.html: existing home and student authentication pages
- admin.html: Admin signup/login, create subjects, add/edit/delete questions, view results
- student.html: Student selects a subject before starting an exam
- exam.html: Loads questions for the selected subject
- result.html: Displays subject-wise student results
- style.css: Updated responsive styling
- script.js: Application logic

How to run:
1. Extract this ZIP file.
2. Open index.html in a browser.
3. Open Admin from the home page.
4. Use Admin Signup to create an admin account, then log in.
5. Create subjects and add questions under each subject.
6. Register/login as a student, choose a subject, and take the exam.

Important:
This is a frontend academic demonstration. Admin/student credentials and project data are stored in browser Local Storage. This is not secure authentication for a real production system. Data is stored separately in each browser profile.
